## 📖 1. เนื้อเรื่องย่อและรูปแบบเกม
คุณจะได้รับบทเป็น **"ศิษย์ฝึกหัดนักปรุงยา"** ที่ต้องเข้าเวรเฝ้าหอคอยเพียงลำพัง ทว่าเกิดรอยแยกมิติทำให้ฝูงมอนสเตอร์หลุดเข้ามาบุกหอคอย ขณะเดียวกัน "สายธารวัตถุดิบเวทมนตร์" เกิดการขัดข้อง สูบเอาสมุนไพรและแร่ธาตุหลั่งไหลทะลักออกมาตามสายพานอย่างต่อเนื่อง คุณต้องตั้งสติดึงวัตถุดิบลงหม้อให้ตรงตามสูตร ต้มผสมยา แล้วปาขวดยาเวทมนตร์สกัดกั้นฝูงมอนสเตอร์ก่อนที่หอคอยจะแตก!

## 🎮 2. วิธีการเล่นและการควบคุม (Controls)

| การกระทำ (Action) | ปุ่มควบคุม (Key / Mouse) |
|---|---|
| **ดึงวัตถุดิบ (ระบบแทนที่)** | กดปุ่มตัวเลข `1`, `2`, `3`, `4`, `5` เพื่อดึงวัตถุดิบลงหม้อ (ช่องนั้นจะเสกของใหม่มาแทนที่อัตโนมัติ) |
| **ลบวัตถุดิบออกจากหม้อ** | กดปุ่ม `Backspace` เพื่อดึงของชิ้นล่าสุดออกจากหม้อ หรือกด `C` เพื่อล้างหม้อทั้งหมด |
| **ต้มผสมยา (Brew)** | กดปุ่ม `Spacebar` (ต้องมีวัตถุดิบในหม้อ 2-3 ชิ้น และสูตรถูกต้อง) |
| **เลือกขวดยาที่พร้อมใช้** | กดปุ่มคีย์ลัด `Q`, `W`, `E`, `R` หรือ **คลิกเมาส์ซ้าย** ที่ช่องพักยา |
| **เล็งและปาขวดยา** | เลื่อนเมาส์ไปยังเลนมอนสเตอร์ด้านบน แล้ว **คลิกเมาส์ซ้าย** เพื่อปา |
| **เปิด/ปิด สมุดสูตรยา** | กดปุ่ม `Tab` หรือ `H` หรือคลิกที่คัมภีร์มุมขวาล่าง |
| **โหมดเต็มจอ (Fullscreen)** | กดปุ่ม `F11` หรือกดปุ่มขยายหน้าต่าง (Maximize) |
| **ออกจากเกม / กลับเมนู** | กดปุ่ม `Esc` |

## 🏰 3. ระบบด่าน (Stage Progression) & การอัปเกรดเวทมนตร์ (Magic Upgrades)

เพื่อแก้ปัญหาผู้เล่นใหม่สับสนกับวัตถุดิบและสูตรยาที่เยอะเกินไป ตัวเกมจึงปรับเป็น **ระบบการเรียนรู้แบบค่อยเป็นค่อยไป (Gradual Learning Curve)**:

### ลำดับด่าน (Stages)
1. **ด่านที่ 1: มือใหม่หัดปรุง (Apprentice)**  
   - **วัตถุดิบ (2 ชนิด):** สมุนไพรเพลิง, ผลึกน้ำแข็ง  
   - **มอนสเตอร์ (2 ชนิด):** อสูรพฤกษา (แพ้ไฟ 🔥) และ โกเลมไฟ (แพ้น้ำแข็ง ❄️)  
   - **เป้าหมาย:** ทำความเข้าใจคอนเซปต์ธาตุตรงข้ามและการผสมยาคู่เบื้องต้น
2. **ด่านที่ 2: หมอกพิษและเกราะหิน (Acid & Armor)**  
   - **วัตถุดิบเพิ่มขึ้น (3 ชนิด):** เพิ่ม เห็ดพิษ  
   - **มอนสเตอร์เพิ่มขึ้น (3 ชนิด):** เพิ่ม สัตว์ร้ายหุ้มเกราะ (แพ้กรดพิษ 🧪)  
   - **เป้าหมาย:** จัดการมอนสเตอร์เกราะหนาที่เดินช้าแต่เลือดเยอะด้วยยากรดกัดกร่อน
3. **ด่านที่ 3: พายุคลั่งและหายนะ (Storm & Chaos)**  
   - **ครบทุกวัตถุดิบ (4 ชนิด):** เพิ่ม รากสายฟ้า  
   - **มอนสเตอร์ครบทุกชนิด (4 ชนิด):** เพิ่ม อิมป์ว่องไว (แพ้สายฟ้า ⚡)  
   - **เป้าหมาย:** สปีดและความแม่นยำขั้นสูงสุด ปรุงยาสายฟ้าหยุดยั้งศัตรู และยาระเบิดกวาดล้าง
4. **โหมดท้าทาย: ไร้ขีดจำกัด (Endless Mode)**  
   - ปลดล็อกเมื่อผ่านด่านที่ 3 เอาชีวิตรอดจากเวฟมอนสเตอร์ไม่รู้จบเพื่อทำคะแนนสถิติสูงสุด!

### ระบบประเมิน 1-3 ดาว (Star Rating)
เมื่อผ่านด่าน จะได้รับดาวตามสภาพของหอคอย:
- ⭐⭐⭐ **3 ดาว (สมบูรณ์แบบ):** หอคอยไม่ได้รับความเสียหายแม้แต่น้อย (HP 100%)
- ⭐⭐ **2 ดาว (ยอดเยี่ยม):** หอคอยคงเหลือพลังชีวิตมากกว่า 50%
- ⭐ **1 ดาว (ผ่านด่าน):** เอาชีวิตรอดจนจบทุกเวฟได้สำเร็จ

### ร้านอัปเกรดสกิลเวทมนตร์ (Magic Upgrades)
นำดาวที่ได้จากแต่ละด่านมาอัปเกรดสกิลถาวรที่หน้าเลือกด่าน:
1. 🛡️ **หอคอยทนทาน (Tower Max HP):** เพิ่ม HP สูงสุด +30 ต่อขั้น (สูงสุด Lv.3)
2. ⚡ **สายพานรวดเร็ว (Conveyor Speed):** เร่งความเร็วในการเสกของใหม่มาแทนที่ (สูงสุด Lv.3)
3. 💥 **ระเบิดวงกว้าง (Potion Radius):** ขยายรัศมีระเบิดของยาทุกชนิด +15% ต่อขั้น (สูงสุด Lv.3)
4. ⏳ **ฟื้นฟูหม้อไว (Cauldron Recovery):** ลดเวลาคูลดาวน์เมื่อหม้อต้มระเบิดจากการใส่สูตรผิด (สูงสุด Lv.3)

## 🧪 4. ตารางสูตรยาและจุดอ่อนมอนสเตอร์ (Elemental Matrix)

### ระบบเกราะธาตุเด็ดขาด (Strict Resistance) & คอมโบ (Combo)
- **ปาผิดธาตุ:** มอนสเตอร์จะขึ้น `RESIST! 🛡️` ดาเมจเข้าเพียง 15% (ป้องกันการกดมั่ว)
- **ปาตรงจุดอ่อน:** เกิด `CRITICAL! 💥` ดาเมจแรงขึ้น **2.5 เท่า** พร้อมสะสม `COMBO x2, x3...` ทวีคูณคะแนน
- **หม้อระเบิด (Explosion Penalty):** หากต้มสูตรผิด หม้อจะระเบิดควันดำพุ่งและติดคูลดาวน์ห้ามต้ม 2 วินาที!
- **ป้ายนำทาง (Visual Weakness Badge):** มีไอคอนขวดยาและธาตุแพ้ทางแสดงชัดเจนบนหัวมอนสเตอร์ทุกตัว

### สูตรการผสมยา (Recipes)
- 🔥 **ยาเพลิงกัลป์ (Fire Potion):** `สมุนไพรเพลิง x2` ➔ ปราบ **อสูรพฤกษา 🌿** (ระเบิดหมู่ AOE + เผาไหม้ Burn)
- 🧊 **ยาน้ำแข็ง (Ice Potion):** `ผลึกน้ำแข็ง x2` ➔ ปราบ **โกเลมไฟ 🔥** (ดาเมจน้ำแข็ง + สโลว์ 50%)
- 🧪 **ยากรดพิษ (Acid/Poison):** `เห็ดพิษ x2` ➔ ปราบ **สัตว์ร้ายเกราะ 🛡️** (ละลายเกราะ + ดาเมจพิษต่อเนื่อง)
- ⚡ **ยาสายฟ้า (Lightning Potion):** `รากสายฟ้า x2` ➔ ปราบ **อิมป์ว่องไว ⚡** (ดาเมจสูง + ชะงัก Stun)
- 💥 **ยาระเบิดเวท (Explosive):** `สมุนไพรเพลิง + รากสายฟ้า` ➔ ระเบิดกวาดล้างรัศมีกว้างมาก

## 🏛️ 4. สถาปัตยกรรม OOP (4 เสาหลักของวิชา)

1. **Encapsulation (การห่อหุ้ม):**
   - ตัวแปรสถานะทั้งหมดของ `Monster`, `Potion`, `Tower`, `Cauldron` กำหนดเป็น `private`/`protected`
   - ป้องกันการแก้ไขสถานะโดยตรงจากภายนอก ควบคุมผ่าน Getter/Setter และเมธอดคำนวณ เช่น `takeDamage()`, `applyStatus()`
2. **Inheritance (การสืบทอด):**
   - คลาสแม่ `Monster` สืบทอดไปยัง `FireGolem`, `PlantCreeper`, `ArmoredBeast`, `SwiftImp`
   - คลาสแม่ `Potion` สืบทอดไปยัง `FirePotion`, `IcePotion`, `PoisonPotion`, `LightningPotion`, `FailedPotion`
3. **Polymorphism (การพ้องรูป):**
   - เมธอด `onImpact()` ของ `Potion` แต่ละชนิดสร้างผลกระทบต่อพื้นที่แตกต่างกัน
   - เมธอด `takeDamage()` และการคำนวณจุดอ่อนธาตุทำงานแบบ Dynamic Binding ตามชนิดของมอนสเตอร์โดยไม่ต้องใช้ if-else ดักคลาส
4. **Abstraction (การทำให้นามธรรม):**
   - ใช้งาน Abstract Classes: `Monster`, `Potion`
   - ใช้งาน Interfaces: `Damageable`, `Renderable` เพื่อกำหนดสัญญาการทำงาน

## 🚀 5. วิธีการรันโปรแกรม

### วิธีที่ 1: ผ่านสคริปต์ Terminal (แนะนำ)
เปิด Terminal ที่โฟลเดอร์โปรเจกต์ แล้วพิมพ์คำสั่ง:
```bash
./run.sh
```

### วิธีที่ 2: รันผ่าน IntelliJ IDEA หรือ Eclipse
1. เปิดโฟลเดอร์ `POTION_PANIC_OOP` ใน IntelliJ หรือ Eclipse
2. โปรแกรมจะตรวจพบเป็น Maven Project อัตโนมัติ
3. ไปที่ไฟล์ `src/main/java/com/potionpanic/Main.java` แล้วกดปุ่ม **Run** (สีเขียว)
