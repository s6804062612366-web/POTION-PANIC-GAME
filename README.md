## 1. เนื้อเรื่องย่อและรูปแบบเกม
คุณจะได้รับบทเป็น **"ศิษย์ฝึกหัดนักปรุงยา"** ที่ต้องเข้าเวรเฝ้าหอคอยเวทมนตร์เพียงลำพัง ทว่าเกิดรอยแยกมิติทำให้ฝูงมอนสเตอร์หลุดเข้ามาบุกหอคอย ขณะเดียวกัน "สายธารวัตถุดิบเวทมนตร์" เกิดการขัดข้อง สูบเอาสมุนไพรและแร่ธาตุหลั่งไหลทะลักออกมาตามสายพานอย่างต่อเนื่อง คุณต้องตั้งสติดึงวัตถุดิบลงหม้อให้ตรงตามตำราเวทมนตร์ 3 ชนิด ต้มผสมยา แล้วปาขวดยาเวทมนตร์สกัดกั้นฝูงมอนสเตอร์และบอสใหญ่ก่อนที่หอคอยจะพังทลาย

## 2. วิธีการเล่นและการควบคุม (Controls)

| การกระทำ (Action) | ปุ่มควบคุม (Key / Mouse) | รายละเอียด |
|---|---|---|
| **ดึงวัตถุดิบลงหม้อ** | กดปุ่มตัวเลข `1`, `2`, `3`, `4`, `5` | ดึงวัตถุดิบจากช่องสายพานลงหม้อต้ม (ช่องนั้นจะเสกของใหม่มาแทนที่อัตโนมัติ) |
| **สุ่มของใหม่ทั้งสายพาน (Reroll)** | กดปุ่ม `F` | ล้างและสุ่มวัตถุดิบใหม่ทั้ง 5 ช่องบนสายพานทันที (คูลดาวน์ลดเหลือ 1.0 วินาที พร้อมรับประกันสูตรแก้ทางศัตรูตัวหน้าสุด 100%) |
| **ลบวัตถุดิบออกจากหม้อ** | กดปุ่ม `Backspace` | ดึงวัตถุดิบชิ้นล่าสุดออกจากหม้อ หรือกดล้างหม้อที่ระเบิดควัน |
| **ล้างหม้อต้มทั้งหมด** | กดปุ่ม `C` | ล้างวัตถุดิบทั้งหมดที่ค้างอยู่ในหม้อต้มทิ้งทันที |
| **ต้มผสมยา (Brew)** | กดปุ่ม `Spacebar` | ผสมยาเมื่อมีวัตถุดิบครบ 3 ชิ้น หากใส่ครบ 2 ชิ้นจะมีคาถาชี้แนะแสดงขึ้นเหนือหม้อ |
| **เลือกขวดยาที่พร้อมใช้** | กดปุ่ม `Q`, `W`, `E`, `R` หรือ **คลิกเมาส์ซ้าย** | สลับเลือกช่องพักยาที่ 1 ถึง 4 เพื่อเตรียมนำไปปา |
| **เล็งและปาขวดยา** | เลื่อนเมาส์ไปยังเลนมอนสเตอร์ แล้ว **คลิกเมาส์ซ้าย** | เล็งเป้าหมายพร้อมวงรัศมีระเบิด (AoE Radius Circle) แล้วขว้างยา |
| **เปิด/ปิด สมุดสูตรยา (Grimoire)** | กดปุ่ม `Tab` หรือ `H` | เปิดหน้าต่างตำราเวทมนตร์ 3 วัตถุดิบและตารางจุดอ่อนบอส |
| **เปิด/ปิดเสียงเพลงและเอฟเฟกต์ (Mute Toggle)** | กดปุ่ม `M` | สลับเปิด/ปิดเสียงดนตรีประกอบ (BGM) และเสียงเอฟเฟกต์เวทมนตร์ทั้งหมดได้ทันที |
| **เลื่อนการ์ดสอนสูตรก่อนเริ่มด่าน** | กดปุ่ม `A` / `D` หรือ `ลูกศรซ้าย/ขวา` หรือ **คลิกปุ่ม Next/Back** | พลิกการ์ดหน้า 1 (ข้อมูลจุดอ่อนมอนสเตอร์) และหน้า 2 (สมการสูตรยาประจำด่าน) |
| **เริ่มด่านทันทีจากการ์ดสอนสูตร** | กดปุ่ม `Spacebar` หรือ **คลิกปุ่ม Start Game!** | ปิดการ์ดบรรยายสรุปและเริ่มปล่อยเวฟมอนสเตอร์เข้าสู่สนามรบ |
| **โหมดเต็มจอ (Fullscreen)** | กดปุ่ม `F11` | สลับโหมดหน้าต่างปกติ / เต็มหน้าจอ พร้อมระบบรักษาสัดส่วน 16:9 |
| **ออกจากเกม / กลับเมนู** | กดปุ่ม `Esc` | ย้อนกลับสู่หน้าจอเมนูหลัก |

## 3. ระบบด่าน (Stage Progression) & การอัปเกรดเวทมนตร์ (Magic Upgrades)

ตัวเกมมีระบบการเรียนรู้แบบค่อยเป็นค่อยไป (Gradual Learning Curve):

### ลำดับด่าน (Stages)
1. **ด่านที่ 1: มือใหม่หัดปรุง (Apprentice)**  
   - **วัตถุดิบ (2 ชนิด):** สมุนไพรเพลิง, ผลึกน้ำแข็ง  
   - **มอนสเตอร์ (2 ชนิด):** อสูรพฤกษา (แพ้ไฟ) และ โกเลมไฟ (แพ้น้ำแข็ง)  
   - **เป้าหมาย:** ทำความเข้าใจคอนเซปต์ธาตุตรงข้ามและการผสมยา 3 ชิ้นเบื้องต้น
2. **ด่านที่ 2: หมอกพิษและเกราะหิน (Acid & Armor)**  
   - **วัตถุดิบเพิ่มขึ้น (3 ชนิด):** เพิ่ม เห็ดพิษ  
   - **มอนสเตอร์เพิ่มขึ้น (3 ชนิด):** เพิ่ม สัตว์ร้ายหุ้มเกราะ (แพ้กรดพิษ)  
   - **เป้าหมาย:** สกัดกั้นมอนสเตอร์เกราะหนาเลือดเยอะด้วยยากรดพิษกัดกร่อน
3. **ด่านที่ 3: พายุคลั่งและหายนะ (Storm & Chaos)**  
   - **ครบทุกวัตถุดิบ (4 ชนิด):** เพิ่ม รากสายฟ้า  
   - **มอนสเตอร์ครบทุกชนิด (5 ชนิด):** เพิ่ม อิมป์ว่องไว (แพ้สายฟ้า) และ **ราชันย์อสูรเวท (Chaos Overlord - บอสใหญ่)**  
   - **เป้าหมาย:** สปีดและความแม่นยำขั้นสูงสุด ปราบมอนสเตอร์ความเร็วสูง และใช้ยาระเบิดมหาเวททำลายเกราะสลับธาตุของบอสใหญ่
4. **โหมดท้าทาย: ไร้ขีดจำกัด (Endless Mode)**  
   - ปลดล็อกเมื่อผ่านด่านที่ 3 เอาชีวิตรอดจากเวฟมอนสเตอร์ไม่รู้จบ โดยมีราชันย์อสูรเวทปรากฏตัวทุกๆ 3 เวฟเพื่อท้าทายคะแนนสูงสุด

### ระบบประเมินดาว & ช่องทางเก็บดาวสะสม (Star Economy)
ตัวเกมออกแบบให้ผู้เล่นสามารถเก็บดาวสะสมได้อย่างเพียงพอและสมดุลกับ 3 ด่านหลัก:
- **ดาวจากการผ่านด่าน (1-3 ดาว):**
  - **3 ดาว (สมบูรณ์แบบ):** หอคอยไม่ได้รับความเสียหายแม้แต่น้อย (HP 100%)
  - **2 ดาว (ยอดเยี่ยม):** หอคอยคงเหลือพลังชีวิตมากกว่า 50%
  - **1 ดาว (ผ่านด่าน):** ปกป้องหอคอยรอดชีวิตจนจบทุกเวฟได้สำเร็จ
- **โบนัสการเล่นซ้ำ (Replay Bonus):** ชนะด่านเดิมที่เคยผ่านแล้ว จะได้รับ **+1 ดาวโบนัสพิเศษ** เสมอ ทำให้ฟาร์มดาวเพิ่มได้โดยไม่ต้องเล่นไร้ที่ติ
- **โบนัสโหมด Endless:** ได้รับ **+1 ดาว ทุกๆ 2 เวฟ** ที่เอาชีวิตรอดได้

### ร้านอัปเกรดสกิลเวทมนตร์ (Magic Upgrades - 9 Stars Balance)
ปรับสมดุลเพดานอัปเกรดให้พอดีกับดาว 9 ดวงจาก 3 ด่าน (หอคอย 3 ขั้น + สกิลอื่นอย่างละ 2 ขั้น = 9 ดาวเป๊ะ):
1. **หอคอยทนทาน (Tower Max HP):** เพิ่ม HP สูงสุด +30 HP ต่อขั้น (สูงสุด Lv.3 = +90 HP) ใช้ 3 ดาว
2. **สายพานรวดเร็ว (Conveyor Speed):** เร่งความเร็วเสกของใหม่ -0.18 วินาทีต่อขั้น (สูงสุด Lv.2 = 0.24s) ใช้ 2 ดาว
3. **ระเบิดวงกว้าง (Potion Radius):** ขยายรัศมีระเบิดของยาทุกชนิด +22% ต่อขั้น (สูงสุด Lv.2 = 1.44 เท่า) ใช้ 2 ดาว
4. **ฟื้นฟูหม้อไว (Cauldron Recovery):** ลดเวลาคูลดาวน์หม้อระเบิด -0.70 วินาทีต่อขั้น (สูงสุด Lv.2 = 0.60s) ใช้ 2 ดาว
5. **ปุ่มรีเซ็ตสกิล (Upgrade Respec):** สามารถกดคืนดาวทั้งหมด 100% ในหน้าร้านค้า เพื่อปรับเปลี่ยนสายการเล่นได้อย่างอิสระ
*(ผลรวม: 3 + 2 + 2 + 2 = 9 ดาว พอดีกับจำนวนดาวสูงสุดที่ได้จาก 3 ด่านหลัก)*

## 4. ตำราปรุงยา 3 วัตถุดิบและจุดอ่อนมอนสเตอร์ (Alchemy & Elemental Matrix)

### ระบบเกราะธาตุเด็ดขาด (Strict Resistance) & คอมโบ (Combo)
- **ปาผิดธาตุ:** มอนสเตอร์จะต้านทานดาเมจ เหลือรับเพียง 15% พร้อมแสดงข้อความ `RESIST!`
- **ปาตรงจุดอ่อน:** เกิดการระเบิดรุนแรง ได้รับดาเมจ **2.5 เท่า** พร้อมแสดงข้อความ `CRITICAL!` และสะสมตัวคูณคะแนน `COMBO x2, x3...`
- **หม้อระเบิด (Explosion Penalty):** หากต้มสูตรที่ไม่ตรงกับตำรา หม้อจะระเบิดควันดำพุ่งและติดคูลดาวน์
- **ระบบคาถาชี้แนะ (Smart Recipe Helper):** เมื่อใส่ของลงหม้อครบ 2 ชิ้น จะมีลูกโป่งคาถาปรากฏขึ้นเหนือหม้อต้ม แสดงภาพวัตถุดิบชิ้นที่ 3 ที่สามารถใช้ปิดสูตรได้ทันที

### สูตรการผสมยาตามตำรามาตรฐาน (5 Standard Recipes)
1. **ยาเพลิงกัลป์ (Fire Potion):**  
   - สูตร: `สมุนไพรเพลิง x2 + ผลึกน้ำแข็ง x1`  
   - คุณสมบัติ: ระเบิดคลื่นเพลิงวงกว้าง + ติดสถานะเผาไหม้ (Burn) ต่อเนื่อง [ชนะทาง: อสูรพฤกษา]
2. **ยาน้ำแข็ง (Ice Potion):**  
   - สูตร: `ผลึกน้ำแข็ง x2 + สมุนไพรเพลิง x1`  
   - คุณสมบัติ: ไอเย็นเยือกแข็ง + สโลว์ลดความเร็วเดิน 50% [ชนะทาง: โกเลมไฟ]
3. **ยากรดพิษ (Acid / Poison Potion):**  
   - สูตร: `เห็ดพิษ x2 + สมุนไพรเพลิง x1`  
   - คุณสมบัติ: กัดกร่อนทะลุเกราะหนา + ทิ้งบ่อกรดพิษบนพื้นทำดาเมจซ้ำ [ชนะทาง: สัตว์ร้ายเกราะหิน]
4. **ยาสายฟ้า (Lightning Potion):**  
   - สูตร: `รากสายฟ้า x2 + ผลึกน้ำแข็ง x1`  
   - คุณสมบัติ: ดาเมจเฉียบพลัน + เกิดประกายสายฟ้าชิ่ง + ช็อตชะงัก (Stun 1.0s) [ชนะทาง: อิมป์ว่องไว]
5. **ยาหมอกพายุพิษ (Frost-Venom Potion):**  
   - สูตร: `เห็ดพิษ x1 + ผลึกน้ำแข็ง x1 + สมุนไพรเพลิง x1`  
   - คุณสมบัติ: ยาผสมสองธาตุ สโลว์แช่แข็งและติดพิษกัดกร่อนพร้อมกัน [ชนะทาง: โกเลมไฟ และ สัตว์ร้ายเกราะ]

### ของแรร์พิเศษ: ยาระเบิดมหาเวท (Miracle Brew - RARE!)
แก้ปัญหายาระเบิดโกงเกินไป โดยเปลี่ยนจากสูตรผสมตายตัว ให้กลายเป็น **"ของแรร์จากการปรุงยาติดคริติคอล"**:
- **โอกาสได้รับ:** สุ่มติด **15%** จากการปรุงยาตามสูตรมาตรฐาน 5 ชนิดใดก็ได้สำเร็จ และเพิ่มเป็น **25%** ในสถานการณ์คับขัน (เลือดหอคอย $\le 50\%$, มีมอนสเตอร์รุม $\ge 3$ ตัว, หรือเผชิญหน้ากับบอสใหญ่)
- **คุณสมบัติ:** ธาตุสากล (Universal) ทะลวงเกราะทุกชนิด และสร้างความเสียหายฉีกเกราะ **ราชันย์อสูรเวท (Chaos Overlord)** ถึง **3 เท่า!** ไว้นำมาพลิกสถานการณ์ยามฉุกเฉิน

### ระบบการเสกวัตถุดิบอัจฉริยะตามภัยคุกคาม (Smart Threat-Aware Alchemy Spawning)
แก้ปัญหาความหงุดหงิดจากการสุ่มวัตถุดิบไม่ตรงกับมอนสเตอร์ที่กำลังบุกมาด้วยระบบชั่งน้ำหนัก 3 ลำดับชั้น:
1. **การันตีสูตรแก้ทางศัตรูที่ใกล้ที่สุด (Active Threat Priority & Zero-Starvation):** สแกนมอนสเตอร์ที่ใกล้หอคอยที่สุด ดึงสูตรยาที่ชนะทาง หากบนสายพานยังขาดวัตถุดิบชิ้นใด ระบบจะเร่งสุ่มชิ้นนั้นลงมาด้วยน้ำหนักความสำคัญสูงถึง 85%
2. **เติมเต็มหม้อที่เริ่มปรุงแล้ว (Cauldron Finisher Synergy):** หากในหม้อต้มมีวัตถุดิบแล้ว 1-2 ชิ้น ระบบจะค้นหาวัตถุดิบชิ้นที่ 3 ที่จะทำให้ปรุงสำเร็จ แล้วเพิ่มโอกาสสุ่มลงสายพาน 80% ทันที
3. **การันตี Reroll 100% (Smart Guaranteed Reroll):** เมื่อกดปุ่ม `[F]` (คูลดาวน์ลดเหลือ 1.0 วินาที) ระบบจะรับประกันว่าบนสายพานจะมีวัตถุดิบครบทั้ง 3 ชิ้นสำหรับปรุงยาปราบมอนสเตอร์ตัวหน้าสุดอย่างแน่นอน ไม่ต้องเสียเวลานั่งสุ่มทิ้งซ้ำๆ

## 5. กราฟิกภาพแฟนตาซี 2D คุณภาพสูง เอนจินอนิเมชัน และระบบสมการภาพ (Visual & Audio Experience)

ตัวเกมได้รับการออกแบบให้มีสไตล์ภาพและงานศิลปะที่สวยงาม ปราณีต เข้ากับบรรยากาศห้องปรุงยาเวทมนตร์ โดยคงนโยบาย **ห้ามใช้อีโมจิ (Zero Emojis)** อย่างเคร่งครัดในทุกส่วน:
- **ภาพประกอบดิจิทัลแฟนตาซี 2D (High-Resolution Cel-Shaded Assets):** นำเข้าและเรนเดอร์ภาพความละเอียดสูงผ่าน `AssetLoader` ครบทั้ง 20 ภาพ ครอบคลุมฉากห้องปรุงยายามค่ำคืน (Title Screen), ฉากสนามรบ 3 โซนอันทรงพลัง (Battlefield Background), สไปรต์บอสใหญ่ ราชันย์อสูรเวท (Chaos Overlord), ขวดยา 7 ชนิด, วัตถุดิบ 4 ชนิด, และมอนสเตอร์ทุกตัว
- **การ์ดสรุปข้อมูลและสอนสูตรก่อนเริ่มด่านแบบตอบสนอง (Responsive Stage Briefing Overlay):**
  - *หน้า 1 (มอนสเตอร์):* การ์ดปรับความสูงอัตโนมัติตามจำนวนมอนสเตอร์ (เช่น ด่าน 3 มี 5 ชนิด จะจัดเป็นการ์ดกะทัดรัด ไม่ล้นกรอบและไม่ชนปุ่ม Next)
  - *หน้า 2 (สูตรยา):* จัดวางสูตรยาเป็นโครงสร้างตาราง 2 คอลัมน์ (2-Column Grid) เมื่อสูตรมีมากกว่า 3 ชนิด ไม่ล้นขอบล่าง
  - รองรับการควบคุมด้วยคีย์บอร์ด `[A] / [D]` หรือลูกศรซ้าย/ขวา และกด `[Spacebar]` เพื่อเริ่มเล่นทันที
- **การจัดระยะพื้นที่ทำงานปลอดการชนกัน (Clearance & Spatial Layout):** จัดตำแหน่งหม้อต้มยาและแท่นพักยาโดยเว้นระยะห่าง 20 พิกเซล ป้องกันลูกโป่งคาถาชี้แนะชนสายพานด้านบนหรือชนแท่นพักยาด้านขวา พร้อมปรับระยะขอบกระดานสูตรด่วนให้มีพื้นที่ชัดเจนสวยงาม
- **การนำเสนอสูตรยาแบบสมการไอคอนภาพ (Visual Equation Presentation):** แทนที่การอ่านข้อความยาวๆ ด้วยสมการรูปภาพ `[ไอคอนวัตถุดิบ] + [ไอคอนวัตถุดิบ] + [ไอคอนวัตถุดิบ] = [ไอคอนขวดยา] -> [ไอคอนมอนสเตอร์ที่แพ้ทาง]` ทั้งบนกระดานสูตรด่วนหน้าจอเล่นเกม, ในสมุดตำราเวทมนตร์ (Recipe Grimoire), และเหนือหม้อต้มยา
- **ระบบอนิเมชันและการตอบสนองแบบไดนามิก (Visual Juice & Animation Engine):**
  - *Flying Items:* ไอเทมลอยโค้งพาราโบลาพร้อมละอองแสงเวทเมื่อดึงจากสายพานลงหม้อต้ม และเมื่อปรุงยาเสร็จลอยเข้าแท่นพักยา
  - *Squash & Stretch Walk Cycle:* มอนสเตอร์ขยับยืดหดตัวตามจังหวะก้าวเดินอย่างเป็นธรรมชาติ
  - *Hit Flash & Damage Numbers:* มอนสเตอร์กะพริบขาวเมื่อโดนโจมตี พร้อมตัวเลขดาเมจลอยละล่อง
  - *Death Burst Particles:* มอนสเตอร์ระเบิดสลายเป็นละอองอนุภาคตามแรงโน้มถ่วงเมื่อพ่ายแพ้
  - *Screen Shake:* หน้าจอสั่นสะเทือนตามน้ำหนักเมื่อเกิดการระเบิดรุนแรงหรือหอคอยโดนโจมตี
  - *Wave Announcement Banner:* แถบประกาศเวฟเคลื่อนไหวสไลด์ลงมาอย่างตระการตา
- **ระบบเสียงดนตรีสังเคราะห์หลายแทร็ก (Multi-Track 16-bit Polyphonic Synthesizer):** ขับกล่อมบรรยากาศด้วยเพลงสไตล์เซลติกโบราณในหน้าเมนู (Mystic Alchemist Chamber) และเพลงจังหวะสนุกสนานเร้าใจสไตล์ทาเวิร์นในฉากต่อสู้ (Upbeat Tavern Alchemy Groove) พร้อมปุ่มลัด `[M]` สลับเปิด/ปิดเสียงได้ทันที
- **ระบบสำรองภาพเวกเตอร์ (Procedural Vector Art Fallback):** หากไฟล์ภาพสูญหายหรือโหลดไม่สำเร็จ ระบบจะสลับไปใช้ `VectorArtRenderer` ที่วาดด้วย Java Graphics2D ทันทีโดยเกมไม่หยุดชะงัก

## 6. สถาปัตยกรรมเชิงวัตถุ (OOP Architecture - 4 Pillars)

1. **Encapsulation (การห่อหุ้มข้อมูล):**
   - ฟิลด์สถานะทั้งหมดของ `Monster`, `Potion`, `Tower`, `Cauldron` กำหนดเป็น `private`/`protected`
   - ป้องกันการดัดแปลงค่าสถานะโดยตรงจากภายนอก ควบคุมผ่าน Getter/Setter และเมธอดคำนวณ เช่น `takeDamage()`, `applyStatus()`
2. **Inheritance (การสืบทอดคุณสมบัติ):**
   - คลาสแม่นามธรรม `Monster` สืบทอดไปยัง `FireGolem`, `PlantCreeper`, `ArmoredBeast`, `SwiftImp`, และ `ChaosBoss`
   - คลาสแม่นามธรรม `Potion` สืบทอดไปยัง `FirePotion`, `IcePotion`, `PoisonPotion`, `LightningPotion`, `FrostVenomPotion`, `ExplosivePotion`, `FailedPotion`
3. **Polymorphism (ภาวะพหุสัณฐาน):**
   - เมธอด `onImpact(...)` ในคลาสลูกของ `Potion` แต่ละชนิดแสดงผลการระเบิดและเอฟเฟกต์เฉพาะตัว
   - เมธอด `takeDamage(...)` และการคำนวณจุดอ่อนธาตุทำงานแบบ Dynamic Dispatch ตามชนิดของมอนสเตอร์
4. **Abstraction (การแยกส่วนนามธรรม):**
   - ใช้งาน Abstract Classes: `Monster`, `Potion`
   - ใช้งาน Interfaces: `Damageable`, `Renderable` เพื่อกำหนดสัญญาการทำงานร่วมกันของทุกอ็อบเจกต์ในเกม

## 7. วิธีการรันโปรแกรม

### วิธีที่ 1: ผ่านสคริปต์ Terminal (แนะนำ)
เปิด Terminal ที่โฟลเดอร์โปรเจกต์ แล้วพิมพ์คำสั่ง:
```bash
./run.sh
```
*(สคริปต์จะค้นหาและกำหนดค่า `JAVA_HOME` ชี้ไปยัง JDK 21 อัตโนมัติ พร้อมคอมไพล์และเปิดเกมทันที)*

### วิธีที่ 2: รันผ่าน IntelliJ IDEA หรือ VS Code
1. เปิดโฟลเดอร์ `POTION_PANIC_OOP` ใน IDE
2. โปรแกรมจะตรวจพบเป็น Maven Project อัตโนมัติ
3. ไปที่ไฟล์ `src/main/java/com/potionpanic/Main.java` แล้วกดปุ่ม **Run**
